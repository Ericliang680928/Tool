# 印章產生器：擴充指南

給之後要加功能的人（包含未來的 AI 助理）。程式只有一個檔案 `index.html`，沒有任何外部套件。

## 1. 程式結構（`index.html` 的 `<script>` 裡，由上到下）

| 區塊 | 作用 |
|---|---|
| `DEFAULTS` | 所有設定的預設值。**新增任何設定都從這裡開始。** |
| 讀取舊設定 | 從瀏覽器 `localStorage`（鍵名 `sealgen.v2`）讀回上次的設定；只收「名稱和型別都符合 `DEFAULTS`」的值，壞掉的自動忽略 |
| 介面產生 | `sl()`（滑桿）、`tx()`（文字框）、`grp()`（可收合的群組）、`trio()`（大小／間距／位置三滑桿）用字串產生控制項 |
| `clampState()` | 依介面上每個滑桿的 min／max、單選項的選項清單，把設定值修正成合法值 |
| `sync()` / `onInput()` | `sync`：設定→畫面；`onInput`：畫面→設定，並存檔、重畫 |
| 繪圖 | `paint()` 清畫布後，依 `s.shape` 呼叫 `SHAPES` 登記的畫法（`drawCompany`、`drawSquare`） |
| `texture()` | 最後一道加工：斑駁效果（只改透明度，不改顏色） |
| 輸出 | `#dl` 下載、`#copy` 複製，都是先 `render()` 再 `toBlob`，所見即所得 |

畫布實際大小 1200×1200，程式裡的座標用 400×400 的「邏輯座標」（`SIZE=400`，中心 `CX,CY=200`），`paint()` 會自動放大 3 倍。

## 2. 新增一個設定（例如「印章邊框顏色」）

1. `DEFAULTS` 加一筆，例如 `frameColor:'same'`。型別要對（字串、數字、true/false），舊設定檔才會正確略過。
2. 在介面產生區加控制項，`data-k` 的名稱就是 `DEFAULTS` 的名稱。
   - 滑桿：`sl('名稱','顯示文字',最小,最大,'單位')`，**範圍只寫這一處**，`clampState()` 會自己讀。
   - 勾選／文字框／單選：照現有寫法，加 `data-k="名稱"`。
3. 在 `drawCompany` 或 `drawSquare`（或 `texture`）用 `s.名稱` 就能取得目前的值。
4. 不需要另外寫存檔、還原、同步的程式，這些都是自動的。

## 3. 新增一種外框形狀

1. 寫一個 `function drawXxx(ctx,col){ … }`，座標用邏輯座標，顏色用 `col`。
2. 加進 `SHAPES`：`const SHAPES={tv:…,oval:…,square:…,xxx:drawXxx}`。
3. 在「外框形狀」的 `.shapes` 裡加一個 `<label class="shape">` 按鈕，`value` 填 `xxx`。
4. 該形狀不需要的欄位，用 CSS class 隱藏：加在 `.grid` 上的模式 class（現有 `sqmode`、`ovalmode`，見 `sync()`）。

## 4. 新增一種輸出（例如 SVG、不同尺寸）

照 `#dl` 的寫法：`render()` → 轉成要的格式 → 觸發下載。若要不同尺寸，改 `cv.width/height` 後重畫再還原（`paint()` 會依 `cv.width` 自動換算比例，`texture()` 的雜訊快取也會依尺寸重建）。

## 5. 測試（改完一定要跑）

1. 用瀏覽器開 `index.html`，按 F12 → Console。
2. 把 `tests/smoke.js` 全部貼上，Enter。
3. 最後一行是 `PASS ✅` 才算過。它會亂填 150 輪、檢查三種形狀都有畫出東西、下載的 PNG 四個角落是透明的。
4. 再人工看一眼：電視型、橢圓形、正方型（陽刻、陰刻）、斑駁 0／35／100、手機寬度（375px）。

## 7. 已知限制

- 字型用的是使用者裝置上的系統字型（標楷體、正黑體等），Windows 最完整；手機或 Mac 會自動換成相近字型，無法保證一樣。要完全一致，必須把字型檔嵌入（檔案會變很大，且要確認字型授權）。
- 斑駁越強，PNG 檔越大（強斑駁時可能到數 MB），因為每個像素的透明度都不一樣。
- 斑駁圖案是固定的（同一個種子），同一張印章每次一樣；不同印章的斑駁位置也會一樣。
- 本工具產生的圖檔僅供內部文件使用，具法律效力的印章仍須正式刻印。

## 8. 可以接著做的功能（建議順序）

1. **換一種斑駁圖案**：`texture()` 的雜訊用固定種子（`fbm(...,1)`、`2`、`3`），加一個 `wearSeed` 設定，改種子即可，快取鍵要加上種子。
2. **輸出尺寸選項**（例如 600／1200／2400 px）。
3. **印章歪一點、不完全對正**：在 `paint()` 外層加一個小角度旋轉，仿真手蓋的感覺。
4. **常用章存檔**：把 `s` 存成多組具名設定（沿用 `localStorage`，另開一個鍵）。
5. **匯出 SVG**（向量檔，可無限放大）：需要把文字轉路徑，工作量較大。
